# 반도체 도메인 지식

필요한 부분만 골라 읽는다.
- 용어와 공정 흐름: `references/glossary.md`
- 데이터 구조와 분석 패턴: `references/analysis-patterns.md`

## 쓰는 원칙
- **과제 README와 업무 담당자의 정의가 이 문서보다 우선한다.** 회사마다 용어와 기준(예: 양품 Bin 번호, 수율 정의)이 다르다.
- 도메인 수치(목표 수율, 기준값)는 지어내지 않는다. 데이터나 담당자 답변에 없으면 "가정"으로 표시하고 설정값으로 뺀다.
- 데이터 단위의 계층을 먼저 확인한다: **Lot → Wafer → Die(Chip)**, **설비(EQP) → 챔버 → 공정 단계(Step) → 레시피**
- 분석 결과는 엔지니어가 행동할 수 있는 형태로 낸다: 어느 설비, 어느 단계, 어떤 기간, 얼마나 차이 나는지.

## 업무 담당자 페르소나별 관심사 (질문하고 요구사항을 해석할 때)
| 역할 | 주로 보는 것 | 자주 원하는 산출물 |
|---|---|---|
| 공정 엔지니어 | 공정 파라미터 산포, 레시피, 수율 변동 원인 | 원인 후보 순위, 파라미터와 수율의 관계 |
| 설비 엔지니어 | 알람, 가동률, PM 주기, 센서 이상 | 이상 감지, 고장 전조, 알람 요약 |
| 수율·품질 엔지니어 | Wafer Map 패턴, Bin 분포, 불량 원인 | 패턴 분류, 공통성 분석, 리포트 |
| 생산관리 | 재공(WIP), Cycle Time, 처리량, 납기 | 병목 파악, 일정과 우선순위 |
| 테스트 엔지니어 | 테스트 항목, Fail Bit, 테스트 시간 | Fail 유형 분류, 테스트 최적화 |
