## A. 사전 체험 15분 (1회뿐, 시험 전까지)

실제 응시할 기기와 장소에서, 휴대폰까지 연결한 상태로 진행합니다. 15분이 빠듯하므로 이 순서대로 합니다.

| 분 | 할 일 | 확인할 것 |
|---|---|---|
| 0–3 | 웹캠, 전체 화면 공유, Proctor 연결 (설치 QR ≠ 연결 QR) | 3개 모두 연결 표시 |
| 3–5 | 터미널: `git clone https://github.com/xxxxKangxxxx/kit ~/kit` | **clone이 되는지** (가장 중요) |
| 5–6 | `cd ~/workspace && bash ~/kit/setup.sh` | AGENTS.md 설치 메시지, 작업 폴더 경로 |
| 6–8 | `codex` → `/status` → `/model` | 모델 목록 (Sol 6.1 / Terra 5.6 / Luna 6 / Sol 6.0), 승인 모드 |
| 8–9 | prompts.md의 0단계 프롬프트 | 규칙 요약이 맞게 나오는지 |
| 9–11 | 작은 서버를 `0.0.0.0`으로 실행 → Browser 도구에서 PORT 입력 | 미리보기 연결 |
| 11–12 | MCP 탭 둘러보기, Cofa Helper에 질문 1개 | |
| 12–13 | 에디터에서 `~/kit/prompts.md`를 열고 복사해서 Codex에 붙여넣기 | **환경 안 복사·붙여넣기가 되는지** |
| 13–15 | "체험 종료" → 예시 서술형 문항 | 서술형 화면 흐름 |

**clone이 안 되면** → 본 시험에서는 킷 없이 진행합니다. AGENTS.md의 핵심 규칙(아래 D절)을 첫 프롬프트로 직접 입력합니다.

### 진행 원칙
- **MVP가 먼저 끝까지 동작**하게 만들고 그다음 확장합니다. 반쯤 만든 기능 여러 개보다 동작하는 기능 하나가 낫습니다.
- Codex가 작업하는 동안 기다리지 말고 **병행**합니다: 담당자 질문, 결과 검토, 문서 확인.
- Codex 상태는 **승인 대기 / 실행 중 / 완료** 세 가지입니다. 승인 대기는 내가 승인해야 진행되니 화면을 자주 확인합니다.
- 같은 요청을 반복하지 않습니다 (토큰 사용량이 추적됨). 두 번 실패하면 접근을 바꿉니다.
- AI 결과를 그대로 받지 말고, 고친 지점을 WORKLOG나 DECISIONS에 남깁니다. 이게 "AI 활용 역량"으로 드러납니다.

## D. 킷을 못 쓸 때 첫 프롬프트 (직접 입력)

```
작업 규칙: 1) README가 최우선이다. 2) git push나 외부 전송은 금지하고, 서버는 0.0.0.0에 바인딩한다. 3) 요구사항을 필수/선택/모호로 나누고 계획을 세운 뒤, 내가 승인하면 구현한다. 4) 단계마다 실행해서 검증하고 로컬 커밋한다. 5) 결정은 DECISIONS.md에 이유와 함께 남긴다. 6) 답은 한국어로 짧게: 한 일, 검증 결과, 이유, 다음 단계.
```

## E. 제출

1. 필수 파일의 경로와 저장 상태("저장됨")를 확인합니다. 충돌 표시가 있으면 해결합니다.
2. 상단 **"제출하고 문제풀기"** → 미리보기 확인 (일부 파일만 표시되는 것은 정상)
3. **"제출물 확정하고 문제풀기"** → 확정 후에는 수정할 수 없습니다.
4. 문제 준비 대기 (약 5분, 최대 10분)

## F. 후속 서술형 (6문항 × 5분, AI 금지, 복사·붙여넣기 불가)

- 질문은 **내 제출물과 작업 기록**을 바탕으로 나옵니다. 그래서 C 단계 2:45 복습이 중요합니다.
- 답변 구조: **결론 한 줄 → 이유 (요구사항, 시간, 리스크) → 대안과 포기한 것 → 검증 방법이나 한계**
- 질문의 전제가 실제 구현과 다르면 **차이를 먼저 밝히고** 내가 실제로 한 것을 설명합니다.
- 5분이 지나면 자동으로 확정되고, 이전 문항으로 돌아갈 수 없습니다. 3분쯤에 핵심을 먼저 적고 나머지를 보강합니다.
- 마지막 문항 → "답안 제출하고 마치기" → **"과제가 잘 제출됐어요"와 제출 ID·시각·파일 수** 확인 후 종료

## G. 문제가 생기면

- 사용법이나 제출 절차 → **Cofa Helper**
- 업무 맥락 → **업무 담당자 (실무자 에이전트)**
- 접속 장애, 반복 오류, 감독 연결 → 상단 **"문제 신고"** (발생 시각, 단계, 직전 동작, 오류 문구. 키나 토큰은 적지 않기)
- 감독 연결이 끊김 → 상단 "감독 연결" → "연결 확인"에서 해당 장치만 다시 연결 (타이머는 계속 흐름)
- 탭을 닫았을 때 → 같은 링크로 재입장 → 카메라·화면 공유·Proctor 다시 연결
